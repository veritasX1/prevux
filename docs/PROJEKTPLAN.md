# Projektplan Prevux

Stand: 5. Oktober 2026 · Version 1.0.0 (Linux)

## Ziel
Bilder und PDFs unter Linux ansehen, markieren, unterschreiben und ausfüllen – so vertraut wie Vorschau auf dem Mac.
Eine Brücke für Menschen, die von macOS kommen.

## Grundsätze
- **Kein Netz, kein Konto:** Prevux öffnet nichts im Internet.
- **Bedienung wie Vorschau** (Apples Gestaltungsrichtlinien), aber als ordentliche GTK-4-App.

## Erreicht (1.0)
- Ansichtsmodi (Einzelseite, Zwei Seiten, Kontaktbogen), Seiten einfügen/umordnen, Miniaturen als neue PDF.
- Markieren, Formen, Text, Unterschrift, Zeichnen mit Druckstärke, Lupe, Lasso, Hintergrund entfernen.
- PDF schützen, verkleinern, exportieren; Live-Text, Lesezeichen, Diashow, Tabs, Versionen.

## Nächste Meilensteine
1. **Testing-Karten abschließen** (Fokus bei Bearbeitung, Symbole, Markdown, Weich scrollen …).
2. **Kontaktbogen:** Hochformatbilder und Beschriftung.
3. **Mehrsprachig:** Englisch und Französisch (App, Hilfe, Seite).
4. **Paketierung:** Flatpak/Ubuntu-Paketquelle.

## Risiken
- Unterschiedliche Linux-Umgebungen (Wayland/X11, Farbprofile).

## Arbeitsweise
Board „Prevux Change Requests“ (Offen → In Arbeit → Testing → Erledigt), Commits mit Karten-Id.
